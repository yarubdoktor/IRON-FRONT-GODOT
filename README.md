# IRON-FRONT — Godot 4

مشروع مستقل لنقل IRON-FRONT 0.16 من React + Three.js إلى Godot 4 / GDScript.

## الحالة الحالية
- النسخة المرجعية 0.16 محفوظة دون تعديل في `reference/IRON-FRONT-0.16-MORE-MINES-SOURCE.zip`.
- فرع العمل: `godot-port`.
- تدقيق المصدر: 82 ملفاً، 35 مجسماً بصيغة GLB، ومنطق لعب TypeScript موزع على أنظمة مستقلة.
- بدأ تأسيس مشروع Godot الأصلي؛ هذا البناء الأولي ليس بعدُ نسخة لعب مكتملة.

## تشغيل المشروع
افتح هذا المجلد من Godot 4.2 أو أحدث، ثم شغّل المشهد الرئيسي.

## قواعد العمل
- لا نعدّل مستودع Newsky أو نسخة الويب 0.16.
- لا ندمج العمل التجريبي في main قبل اجتياز الفحص.
- نحافظ على إحداثيات الخريطة والكاميرا والتحكم باللمس قدر الإمكان.
- ننقل أنظمة اللعب تدريجياً إلى GDScript، مع اختبار كل مرحلة.
