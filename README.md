# IRON-FRONT — Godot 4 Port

هذا المستودع مخصص حصراً لنقل لعبة IRON-FRONT من نسخة الويب إلى مشروع أصلي باستخدام Godot 4 وGDScript.

## المرجع المعتمد
- نسخة الويب المرجعية: IRON-FRONT 0.16 — MORE MINES.
- المستودع الأصلي: https://github.com/yarubdoktor/Newsky
- لا يتم تعديل مشروع الويب أو ملفات APK الخاصة به أثناء هذا النقل.

## قواعد النقل
1. فحص المصدر والأصول قبل إعادة البناء.
2. إعادة استخدام ملفات GLB/GLTF والخامات والصوت المتوافقة.
3. إعادة بناء منطق اللعب داخل Godot؛ لا نعتبر كود React/Three.js قابلاً للتحويل الآلي.
4. الحفاظ على هوية اللعبة وسلوك الكاميرا واللمس والحركة والقتال قدر الإمكان.
5. اختبار كل مرحلة قبل اعتمادها أو دمجها في main.

فرع العمل الحالي: `godot-port`.
